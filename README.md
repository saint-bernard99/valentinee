# 💖 Valentine Interactive Proposal Website

A minimal, interactive Valentine proposal website built with **HTML, CSS, and JavaScript**.

This project delivers a smooth, progressive storytelling experience that ends with a Valentine question — complete with dynamic button behavior, floating hearts, music, and confetti celebration.

---

## ✨ Features

* 🎵 Auto-play favorite song (triggered on user interaction)
* 💬 Multi-step dynamic text flow (without page reload)
* 🎀 Clean pink background with centered blue card layout
* 💙 Rounded interactive buttons
* 😈 Playful “No” button that shrinks while “Yes” grows
* 📝 Optional reason input after multiple “No” clicks
* 🎉 Confetti animation when “Yes” is selected
* 💕 Subtle floating hearts animation
* 📱 Responsive, minimal design

---

## 🧠 How It Works

* The app uses **JavaScript DOM manipulation** to dynamically replace content inside a central container.
* Each “Continue” or “Go On” button advances the step index.
* The Valentine question triggers conditional logic:

  * Clicking **No** increases Yes button size and decreases No size.
  * After multiple No clicks, a reason input appears.
  * Clicking **Yes** triggers confetti and a success message.
* No page reloads occur — everything updates dynamically.
